# Sanitized configuration records

The configuration descriptions here are **not machine-importable Group Policy backups**. They are evidence-led written references to settings configured in the virtual lab.

- [Group Policy, folder permissions, and DHCP/DNS configuration](group-policy-and-acls.md)
- [Full configuration reference](../documentation/configuration-reference.md)
